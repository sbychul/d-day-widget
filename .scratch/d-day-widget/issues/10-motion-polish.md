# 10 — 수정 강조 페이드 인, 상태 줄 올라오기 애니메이션

Status: resolved
Blocked by: 09

## 배경

조작할 때 화면 변화가 갑자기 바뀌어 보인다. 디자인 마이너 업데이트로 짧은 애니메이션 2개를 넣는다(사용자 요청 2026-10-08).

## 범위

- 항목(메인 포함)을 클릭해 수정을 시작하면 강조색(`highlight`)이 투명에서 페이드 인된다. 200ms.
  - 클릭한 순간에만 재생한다. 수정 중에 다시 그려질 때(삭제 확인, 재조회 등)는 재생하지 않는다.
- 상태 줄이 숨김에서 보임으로 바뀌면 아래에서 4px 올라오며 나타난다(투명도 0 → 1). 150ms.
  - 이미 보이는 중에 문구만 바뀌면 재생하지 않는다.
  - 입력칸 위치는 고정이다.
- 2차 범위(사용자 요청 2026-10-08):
  - 상태 줄이 나타날 때 구분선도 함께 올라간다(상태 줄 높이 0 → 24).
  - 상태 줄이 사라질 때(수정 종료, 오류 문구 지움) 사라지는 애니메이션.
  - 일정 추가·삭제 애니메이션.
  - `Delete?`가 나타날 때와, 삭제하지 않고 `×`로 돌아갈 때 애니메이션.
- `prefers-reduced-motion: reduce`이면 모두 끈다.
- 라이브러리를 추가하지 않는다.

## 완료 조건

- localhost(`npx vercel dev`)에서 사용자가 직접 확인하고 승인한다. 승인 전에는 push·배포하지 않는다.
- `npm test`, `npx tsc --noEmit`, `npm run build`가 통과한다.
