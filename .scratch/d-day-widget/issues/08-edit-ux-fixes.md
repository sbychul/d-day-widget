## 배경

사용 피드백 (2026-10-08):

1. 모바일에서도 `수정 중 · Esc로 취소`가 보인다. 모바일 키보드에는 Esc가 없다.
2. 다크 모드에서 수정 중인 항목의 하이라이트(`#28456C`)가 채도가 너무 높다.
3. 상태 줄이 입력칸 아래에 생기면서 입력칸이 26px 위로 밀린다. 입력 오류 문구도 마찬가지다.

Figma 시안: 페이지 `03 수정안 (2026-10-08)` (https://www.figma.com/design/QmqZtbIUqhJNng8R6xPUVl?node-id=14-2)

## 범위

- 상태 줄을 입력칸 위(아래 구분선과 입력칸 사이)로 옮긴다. 수정 중 문구와 오류 문구 모두 해당된다. 상태 줄이 생겨도 입력칸 위치는 그대로이고, 목록 영역이 줄어든다.
- 수정 중 문구를 `수정 중`으로 바꾸고, 상태 줄 오른쪽에 `취소` 버튼을 둔다(모바일·데스크톱 공통). Esc 취소는 유지한다.
- 다크 `highlight`를 `#1F2F40`으로 바꾼다.
- AGENTS.md, spec.md, README, Figma `02 화면`·`Theme` 변수를 함께 갱신한다.

## 완료 조건

- 기본/수정 중/입력 오류 상태에서 입력칸 위치가 같다.
- `취소` 버튼을 누르면 수정 모드가 해제되고 입력칸이 비워진다.
- `npm test`, `npm run build`가 통과한다.
