## 한 일
- 1차 프로토타입 피드백을 반영했다. 강조 페이드는 승인받았다.
- 상태 줄은 나타날 때 높이도 0 → 24로 커진다. 그래서 목록 아래 구분선이 튀지 않고 같이 올라간다.
- 상태 줄이 사라질 때(수정 종료, 오류 문구 지움) 4px 내려가며 투명도와 높이가 0이 된다. 사라지는 동안 이전 문구를 유지하고, 150ms 뒤 `hidden`으로 바꾼다.
- 일정을 추가하면 행이 높이 0 → 34로 커지며 나타난다. 새 일정이 메인이 되면 메인이 올라오며 나타난다.
- 일정을 삭제하면 행은 높이가 0으로 줄고, 메인은 내려가며 사라진다. 150ms 뒤 제거하고 DELETE한다. 메인을 지우면 다음 메인이 올라오며 나타난다.
- `Delete?`는 나타날 때 올라오고, 3초 뒤 `×`로 돌아갈 때 내려가며 사라진다.
- 구조:
  - 나타나는 효과는 일회성 플래그(`enterId`, `mainEnter`, `confirmEnter`, `fadeInId`)로 처리한다. `render()` 끝에서 비우므로, 다른 이유로 다시 그려질 때는 재생하지 않는다.
  - 사라지는 효과는 `leave` 클래스를 붙이고 `exitDelay()`(150ms, reduced-motion이면 0) 타이머 뒤에 실제로 제거한다. `animationend` 대신 타이머를 쓰는 이유는 두 가지다. reduced-motion에서는 이벤트가 오지 않고, 행이 다시 만들어지면 이벤트를 놓친다.
